# 戒色打卡

自律者自由 · 每一天的坚持都算数。

一个纯前端的戒色打卡网页，数据保存在浏览器本地（localStorage），无需服务器。

## 功能

- **连续天数打卡**：首页大数字 + 金色进度环展示当前连续坚持天数
- **阶段目标**：自定义 7/14/21/30/60/90 天目标，达成触发庆祝动效
- **打卡日历**：月度视图，绿色标记已打卡、红底标记破戒日
- **里程碑系统**：3 天到 365 天共 9 档成就
- **破戒诱因分析**：记录诱因并给出针对性建议
- **心情日记**：打卡时记录心情和一句话
- **成就动效**：达成目标/里程碑时弹出徽章卡片 + 全屏彩纸

## 使用

直接用浏览器打开 `index.html` 即可，或通过 GitHub Pages 在线访问。

## 隐私

所有数据仅保存在浏览器 localStorage，不会上传到任何服务器。
